# Real-Time Industrial Defect Detection System

## Overview

A computer vision system for detecting and classifying industrial
surface defects using deep learning and real-time image processing.

## Objective

The system is designed to detect six types of surface defects:

- Crazing
- Inclusion
- Patches
- Pitted Surface
- Rolled-in Scale
- Scratches

## Dataset

NEU Surface Defect Database.

## Technology Stack

- Python
- PyTorch
- YOLOv8
- OpenCV
- Albumentations
- ONNX Runtime / TensorRT
- FastAPI
- Prometheus
- Grafana
- Docker
